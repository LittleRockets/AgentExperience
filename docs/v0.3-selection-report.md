# V0.3 adaptive-selection reference report

Date: 2026-08-21  
Environment: Windows, Python 3.13, local process  
Dataset: `synthetic-reference-v1`  
Artifact: `baseline-adaptive-selection-v030-results.json`

The 100-run reference check produced one deterministic output, zero hard-constraint bypasses and
0.0521 ms median / 0.0559 ms p95 selector latency. The 40-case synthetic holdout reported 1.0
selection precision, 0 negative-transfer rate, 0.75 coverage, 1.0 abstention quality, 0.10 expected
calibration error and paired net benefit 0.75 (95% normal interval 0.6141 to 0.8859).

These values validate contract mechanics on a deliberately small synthetic fixture. They do not
show that AgentExperience improves an external model, framework or production workload. The
release artifact therefore labels both the dataset and limitations, and the v0.3 evaluation API
requires source/task split checks so a later real-task study can report leakage explicitly.

Reproduce with:

```powershell
$env:PYTHONPATH = "src"
python tools/adaptive_selection_effects.py --samples 100 `
  --output baseline-adaptive-selection-v030-results.json
```
