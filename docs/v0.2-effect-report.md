# v0.2 Protocol Effect Report

Date: 2026-08-17  
Environment: Windows, Python 3.13, local append-only Repository  
Command: `python tools/protocol_effects.py`

## Purpose

This benchmark checks whether the v0.2 protocol adds bounded local overhead while preserving its
most important safety property: when no applicable ACTIVE experience exists, the runtime abstains
and never changes Harness behavior.

## Result

| Metric | Result |
| --- | ---: |
| Sequential samples | 100 |
| Protocol median | 1.745 ms |
| Protocol p95 | 3.102 ms |
| Protocol maximum | 7.682 ms |
| Concurrent runs | 100 |
| Concurrent total | 27.627 ms |
| Unique concurrent run IDs | 100 |
| Abstention rate without ACTIVE experience | 100% |
| Automatic experience applications | 0 |
| Active sessions after test | 0 |
| Integrity-verified events | 500 |

The run passed the local 25 ms p95 budget. These numbers are a reproducible development baseline,
not a cross-platform service-level guarantee. CI and release candidates should retain results per
OS, Python version, storage medium and durability policy instead of comparing unlike environments.
