# v0.2 Baseline-AgentExperience Test Report

Date: 2026-08-17  
Environment: Windows, Python 3.13, local append-only Repository  
Command: `python tools/baseline_agentexperience.py --samples-per-cohort 50`

## Question

Does the v0.2 Experience Protocol preserve baseline Harness behavior when it abstains, and can an
external Harness improve a deterministic task cohort when it explicitly adopts applicable ACTIVE
experience?

## Method

The benchmark uses 100 balanced synthetic tasks and a two-attempt Harness budget:

- 50 relevant dependency-debugging tasks;
- 50 unrelated formatting tasks used as the negative-transfer cohort.

The same tasks run through three arms:

1. `baseline`: fixed Harness strategy order, without AgentExperience;
2. `instrumented_abstain`: AgentExperience records the run but has no ACTIVE experience;
3. `experience_assisted`: one ACTIVE, capability-scoped experience is available and the Harness
   explicitly adopts selected advice.

The task oracle, attempt budget and baseline order are fixed. AgentExperience never executes or
changes the Loop itself.

## Result

| Metric | Baseline | Instrumented / abstain | Experience-assisted |
| --- | ---: | ---: | ---: |
| Total success rate | 50% | 50% | 100% |
| Relevant-cohort success | 0% | 0% | 100% |
| Unrelated-cohort success | 100% | 100% | 100% |
| Mean attempts | 1.50 | 1.50 | 1.00 |
| Selection rate | 0% | 0% | 50% |
| Adoption rate | 0% | 0% | 50% |
| Abstention rate | n/a | 100% | 50% |
| Median local latency | 0.0004 ms | 1.5824 ms | 1.8780 ms |

Safety and audit checks:

- abstention behavioral parity: passed;
- negative transfers: 0/100;
- unrelated-cohort regression: 0/50;
- accepted `EXPERIENCE_APPLIED` events: 50;
- active sessions after each protocol arm: 0;
- integrity-verified events: 300 in the abstain arm and 351 in the assisted arm.

Overall benchmark verdict: **PASS**.

## Interpretation and limits

This establishes a reproducible functional baseline for selection, abstention, explicit adoption,
feedback and event integrity. It demonstrates that a correctly scoped experience can alter an
external Harness strategy without hidden Loop ownership, while missing applicability leaves task
behavior unchanged.

The 50 percentage-point gain is constructed by the deterministic fixture and is not evidence of
real-world model quality or causal learning. The latency values are local development measurements,
not an SLA. A release-quality effectiveness claim still requires frozen real-task datasets, paired
runs across multiple seeds/models, confidence intervals, cost/risk accounting and independently
validated outcomes.

The machine-readable result is stored in `baseline-agentexperience-results.json` and the executable
benchmark in `tools/baseline_agentexperience.py`.
